# fitnes-objave

Carouseli za @fitnesdanijel (Instagram, TikTok).

- `objave/dan-XX/` – končni slajdi (JPG, 1080 × 1350), ki jih prevzame Metricool
- `predloga/slajdi/` – predloga 7 slajdov (naslovnica, 5 navad, zaključek)
- `lik/` – izrezane poze lika (prozoren PNG); `lik-10-san.png` je cel prizor
- `orodja/` – skripti za izrez ozadja (`cut.py`) in izris slajdov (`render.py`)

Paleta: modra `#1F3BE0`, krem `#FBF3E2`, črna `#111111`. Pisavi: Barlow Condensed (naslovi), Barlow (besedilo).
Ritem objav: ponedeljek, sreda, petek ob 10:00 (Europe/Ljubljana), Instagram + TikTok.
